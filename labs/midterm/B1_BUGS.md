## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

|---|---|---|---|
| กดปุ่มไม่ได้ แต่พอโหลดหน้าเสร็จฟังก์ชันทำงานเองทันที | `Foo.jsx : 12` | เขียน `onClick={handleClick()}` มีวงเล็บ → JavaScript **เรียกฟังก์ชันทันที**ตอน render แล้วเอาค่าที่ return มาเป็น handler | เอาวงเล็บออก เป็น `onClick={handleClick}` (ส่งตัวฟังก์ชัน ไม่ใช่ผลลัพธ์) |

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) | `src/components/RequestList.jsx : 7` | ตอนใช้ .map() สร้างการ์ด ไม่ได้ใส่ prop key ให้มัน React เลยเตือนเพราะตามจับการเปลี่ยนแปลงไม่ได้ | เพิ่ม `key={request.id}` เข้าไปใน `<RequestCard>` |
| 2 | ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็นจริง | `src/pages/DashboardPage.jsx : 43` | ตัวแปร pending ดันไปนับจำนวนจากเงื่อนไข `status === 'completed'` แทนที่จะเป็น pending | เปลี่ยนเงื่อนไขจาก `'completed'` เป็น `'pending'` |
| 3 | กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่ | `src/pages/DashboardPage.jsx : 51` | โค้ดใช้เครื่องหมาย `!==` (ไม่เท่ากับ) ทำให้มันดึงทุกรายการที่ไม่ตรงกับปุ่มที่เรากดมาแสดง | เปลี่ยนเครื่องหมายจาก `!==` เป็น `===` |
| 4 | เปลี่ยน URL `REQ-001` → `REQ-002` แล้วข้อมูลไม่เปลี่ยน | `src/pages/RequestDetailPage.jsx : 23` | ลืมใส่ `requestId` ใน Dependency Array ของ useEffect พอเปลี่ยน URL ค่า ID เปลี่ยนแต่ฟังก์ชันดึงข้อมูลเลยไม่ยอมทำงานใหม่ | เพิ่ม `requestId` เข้าไปในวงเล็บก้ามปู เป็น `[requestId, reloadKey]` |
| 5 | กด "ลบ" แล้วรายการยังอยู่ ต้องรีเฟรชถึงหาย | `src/pages/DashboardPage.jsx : 58` | ตอนอัปเดต state ดันเอาตัวแปร `requests` (ข้อมูลชุดเก่าที่ยังไม่ลบ) มาเซ็ตทับ แทนที่จะใช้ `nextRequests` (ข้อมูลใหม่) | เปลี่ยนโค้ดจาก `setRequests(requests)` เป็น `setRequests(nextRequests)` |
| 6 | กด "Reset Demo Data" แล้วหน้าพัง/ว่างเปล่า | `src/pages/DashboardPage.jsx : 68` | ฟังก์ชัน `resetRequests()` เป็น async (คืนค่า Promise) การเอาไปใส่ state ตรงๆ หน้าจอเลยพังเพราะเรนเดอร์ Promise ไม่ได้ | เติมคำว่า `await` ด้านหน้า เป็น `setRequests(await resetRequests())` |
